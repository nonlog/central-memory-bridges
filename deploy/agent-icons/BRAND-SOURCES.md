# React My Work bridge brand assets

The `chatgpt.svg` icon is derived from the OpenAI Blossom identity at https://openai.com/brand/ (original vector paths retained; viewBox tightened). The `hermes.svg` icon is from the NousResearch Hermes Agent project's `assets/icon-master.svg`: https://github.com/NousResearch/hermes-agent.

These icons are used solely to identify the respective agent platforms in the self-hosted Claude-mem viewer. Logos and trademarks remain the property of their respective owners. The remaining icons already existed in this integration before the React UI adaptation.
